# Logos Directory

This directory contains operator/casino brand logos for Odds Pulse.

## Required Logo Files

Save the following logo files in this directory:

### US Sportsbooks
- `fanduel.png` - FanDuel logo (blue shield with 'F')
- `draftkings.png` - DraftKings logo (orange crown with green 'D')
- `betmgm.png` - BetMGM logo (black and white with MGM lion)
- `caesars.png` - Caesars Sportsbook logo (black with laurel wreath)
- `bet365.png` - bet365 logo (green background with white 'bet365')

## File Format
- Preferred: PNG with transparent background
- Alternative: SVG, JPG
- Recommended size: 200-400px width

## Usage
These logos are displayed in:
- Home page operator cards
- Casino comparison grids
- Mobile navigation

All logos are loaded via the `brandLogoUrl` field in `src/data/operators.json`.
